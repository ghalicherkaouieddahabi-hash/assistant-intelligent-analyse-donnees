# Intelligent Data Analysis Assistant

An intelligent data analysis assistant powered by Large Language Models (LLMs), designed to simplify data exploration through natural language.

## Features

- Natural-language interaction for data exploration
- SQL query generation and PostgreSQL integration
- Data cleaning and processing with Python
- Modular data processing pipeline
- Notebook-based workflows for data preparation

## Tech Stack

- **Language:** Python
- **Data Analysis:** Pandas
- **LLM Orchestration:** LangChain
- **Database:** PostgreSQL
- **Interface:** Streamlit

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ghalicherkaouieddahabi-hash/assistant-intelligent-analyse-donnees.git
   cd assistant-intelligent-analyse-donnees
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure the required environment variables using `.env.example` as a template.
